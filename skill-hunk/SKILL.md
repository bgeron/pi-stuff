# Hunk

When this skill is selected, run `hunk skill path` to determine the path to the actual Hunk skill. Then load that skill and follow its instructions.

Generally, in addition to receiving resolutions in the harness, this user would like to receive them as agent comments, too.

Prefer leaving comments replies on the go as you work on them, rather than in one big batch at the end. Don't remove the user's comments when you are done.

If the Hunk session seems to be attached to another checkout/worktree/workspace of your current working directory, you can presume that the comments also apply to cwd. Apply changes in cwd rather than where Hunk is attached.

Never reload the session unless explicitly asked to.
